# AdoptAPet 🐾

AdoptAPet es una aplicación desarrollada con Vue 3 que simula el funcionamiento de un refugio de mascotas.

El proyecto fue creado como práctica integral de desarrollo frontend moderno, aplicando conceptos de arquitectura de componentes, gestión de estado global, navegación dinámica y sincronización de filtros mediante URL.

## Características

- Listado de mascotas
- Filtros por especie, género y edad
- URLs compartibles sincronizadas con filtros
- Estado global utilizando Pinia
- Navegación mediante Vue Router
- Breadcrumbs dinámicos
- Empty States para búsquedas sin resultados
- Sistema de adopción simulado
- Diseño responsive con Bootstrap

## Tecnologías

- Vue 3
- Vite
- Vue Router
- Pinia
- Bootstrap 5
