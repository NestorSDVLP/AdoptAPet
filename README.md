# AdoptAPet 🐾

AdoptAPet es una aplicación desarrollada con Vue 3 que simula la experiencia de adopción de mascotas en un refugio.

El proyecto fue creado como práctica integral de desarrollo frontend moderno, aplicando conceptos de arquitectura escalable, gestión de estado global, navegación dinámica, autenticación de usuarios y diseño responsive.

## ✨ Características

* Listado de mascotas
* Vista de detalle individual
* Mascotas destacadas
* Mascotas relacionadas
* Sistema de adopción simulado
* Contador global de mascotas adoptadas
* Filtros por especie, género y edad
* Sincronización de filtros mediante URL
* URLs compartibles
* Estado global con Pinia
* Navegación mediante Vue Router
* Breadcrumbs dinámicos
* Empty States para búsquedas sin resultados
* Autenticación con Firebase Authentication
* Rutas protegidas
* Diseño responsive para desktop y mobile
* Deploy público en Netlify

## 📦 Instalación

Clonar el repositorio:

```bash
git clone https://github.com/NestorSDVLP/adoptapet.git
```

Instalar dependencias:

```bash
npm install
```

Iniciar entorno de desarrollo:

```bash
npm run dev
```

Generar build de producción:

```bash
npm run build
```
